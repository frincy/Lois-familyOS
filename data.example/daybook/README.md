# Daybook — the chronicle

The COS appends a short note to today's daybook after every meaningful exchange. It's how the **episodic** memory layer accumulates: what actually happened, on what day.

Files are organized by year/month:

```
data/daybook/
  2026/
    05/
      2026-05-22.md
      2026-05-23.md
```

You can read them as a journal of the OS — what got captured, what got opened, what got closed. The end-of-day reflection appends a section to the day's file with "what got done" and "what to carry into tomorrow".

(This README and the year/month folders are placeholders. Real files are written by the COS.)
